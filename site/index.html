Why I Built This

I wanted a faster way to make consistent Boston Dynamics Spot fiducial plates without reopening CAD every time a tag ID, robot name, or logo changed. This tool keeps the template fixed and makes the variable parts quick to update.

Key Features

  • Live SVG preview with fixed Spot plate geometry
  • Validated tag36h11 AprilTag IDs from 001 to 586
  • Purpose-first ID range selection for localization, unspecified, and dock fiducials
  • 500-series dock IDs use a plate layout sized to fit the Spot dock, with a dedicated dock location field
  • Optional built-in, custom, or empty logo handling
  • Separate print-safe and CAD-safe SVG downloads

What The Tool Generates

The generator produces a printable Spot fiducial plate SVG with a fixed 146 mm AprilTag, your company and robot name, and consistent drill hole placement. Useful when your team needs to make new plates without reopening CAD each time.

How To Use It

Choose the fiducial range that matches your workflow, pick a tag36h11 ID from that subset, enter the text that should appear on the plate, and download either a print SVG or a CAD SVG. The browser preview stays close to the final output so you can verify the plate before fabrication. To turn a CAD SVG into a STEP file, follow the SVG to STEP guide.

Quick Answers

This site is a browser-based AprilTag plate generator for Boston Dynamics Spot. It focuses on one fixed plate format rather than a generic marker designer, which helps keep the printable output consistent.

  • The supported tag family is tag36h11.
  • The generated fiducial keeps a fixed 146 mm AprilTag size.
  • The exported files are SVG so they can be printed directly or opened in CAD tools.
  • The app runs client-side on GitHub Pages with no account or backend upload required.
