Spot Fiducial AprilTag Plate Generator

Generate fabrication-ready SVG plates with validated AprilTag IDs, fitted text, optional logo upload, and clean export for print or CAD workflows. The AprilTag size stays fixed at 146 mm for Spot fiducial requirements.

Why I Built This

I wanted a faster way to make consistent Spot fiducial plates without reopening CAD every time a tag ID, robot name, or logo changed. This tool keeps the template fixed and makes the variable parts quick to update.

Key Features

  • Live SVG preview with fixed Spot plate geometry
  • Validated tag36h11 AprilTag IDs from 001 to 586
  • Optional built-in, custom, or empty logo handling
  • Separate print-safe and CAD-safe SVG downloads
